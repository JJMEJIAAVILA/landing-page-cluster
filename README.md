# Landing Page – Arquitectura de Clústeres y Continuidad del Negocio

## 📋 Descripción
Esta landing page presenta de forma clara y visual los conceptos fundamentales relacionados con:
- **Arquitectura de clústeres** en entornos de análisis y desarrollo de software.
- **Continuidad del negocio** y estrategias de recuperación ante desastres (RPO, RTO).
- **Análisis de riesgo, impacto, gestión de prioridad y gestión de crisis**.

El objetivo es ofrecer una introducción amigable y didáctica a estos conceptos clave, utilizando un diseño atractivo con animaciones y secciones bien organizadas.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica del sitio.
- **CSS3**: Animación de fondo con gradiente, diseño de “cards” con efecto de flotación (hover) y estilo responsivo.
- **Visual Studio Code + Live Server**: Para desarrollo y pruebas en tiempo real.

## 🚀 Cómo Ejecutar el Proyecto
1. **Clonar o descargar** este repositorio en tu computadora.
2. Abrir la carpeta en **Visual Studio Code**.
3. Instalar y activar la extensión **Live Server** (si no la tienes instalada).
4. Dar clic derecho en `index.html` → **"Open with Live Server"**.  
   El navegador abrirá automáticamente la landing page.

## 🔑 Contenido de la Landing Page
La página está organizada en secciones:
1. **Portada**: Logo SENA, nombre del autor y datos del programa.
2. **Introducción**: Importancia de la alta disponibilidad y continuidad del negocio.
3. **Objetivo**: Propósito principal del documento.
4. **Desarrollo**:
   - Herramientas y tecnologías para clústeres.
   - Características, tipos y procesamiento en clústeres.
   - Ventajas y desventajas.
   - Conceptos de análisis de riesgo, impacto, RPO, RTO, gestión de crisis y pruebas de operación.
5. **Conclusiones**: Relevancia de estas prácticas para el desarrollo de software.
6. **Referencias**: Enlaces oficiales a tecnologías y documentación.
